War Project 归属规则（2026-09-19 用户定调）：/warproject game start|stop|end 等游戏生命周期指令属于全局命令树（command/WarProjectCommands，唯一注册点）与全局内核 module/GamePhase + module/GameStateService，不得归属任何业务模块；resource / wargame 等模块只订阅阶段变化并在各自包内反应。阶段状态刻意不落盘（开服固定 STOPPED），资源存量落盘到 SavedData war_project_resources。

War Project 资源经济基线（2026-09-19 落地，同日修订为双资源 + 客户端 HUD + 999 硬上限）：node 产出分弹药 ammo 与燃料 fuel（NBT ammo_per_minute / fuel_per_minute，旧键 resource_per_minute 迁移为 ammo），命令 /warproject node setresource <nodeId> <ammoPerMinute> <fuelPerMinute>，FTB 右键菜单 Set ammo output / Set fuel output。resource 包以 ResourceKind(ammo|fuel) 为主键，SavedData war_project_resources 每队 {id, ammo, fuel}，按 Config.resourceSettleIntervalSeconds（默认 5s）分别结算 产出*经过秒数/60，只发给 node 归属且 TeamData 中仍存在的队伍。**两种资源硬上限锁死 999**（ResourceData.MAX_AMOUNT：结算入账 / 管理员 set·add / NBT 读档统一经同一 clamp，旧档超限值读档即压回 999；命令回显实际存量）。game end 清空两队资源并把所有 node 重置 neutral，stop 只冻结增量与消耗。客户端 HUD：client/ResourceClientState + client/ResourceHudOverlay，注册在 VanillaGuiOverlay.HOTBAR 之上，仅 running 且本地玩家有队伍时显示，屏幕正上方居中灵动岛黑胶囊（0xFF000000，左右内边距 8 / 上下 3 / 圆角 = 高度一半），两条「图标 assets/war_project/textures/gui/ammo.png|fuel.png（128×128）+ 当前存量 + '+每60s增量'」。S→C ResourceSyncPacket(running, teams[...]) 在每 5s 结算后、阶段变化后、玩家登录时广播。网络协议号 "4"。教训：GuiGraphics 必须用 11 参数重载 blit(rl, x, y, drawW, drawH, uOffset, vOffset, srcW, srcH, texW, texH)（短重载会把绘制尺寸当采样尺寸，导致 128×128 图标只采左上 16×16 透明角），且 mod 类改动必须重启客户端。
