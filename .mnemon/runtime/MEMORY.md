War Project 全局 HTML 渲染内核（2026-09-20 落地，html 包，不属于任何模块、零依赖）：Css / HtmlNode / HtmlDocument（含解析与 refreshStyles）/ HtmlLayout / HtmlRenderer / HtmlViewHost；支持标签 div span b img button input hr，内联 style 与 <style> 内的 .class / #id / 元素 / :hover / :active 规则，以及圆角（逐行 fill 内缩）、阴影、边框、flex(row,column)、margin/padding/gap、align-items、justify-content、opacity、transform(scale,translate)、transition 时间；关键机制：CSS 规则不烘焙，切换 class 后由 HtmlDocument.refreshStyles() 重新求值（HtmlViewHost 靠 classRevision 检测），否则运行时 setClass 无效；img 必须用 11 参数 blit（drawW,drawH,uOffset,vOffset,srcW,srcH,texW,texH）；数字输入复用 vanilla EditBox，外层外观由内核绘制。灵动岛 client/ResourceIslandView 与转移面板 client/ResourceTransferController 均用它渲染；HTML 文本从 assets/war_project/html/*.html 读取，失败回退代码内置常量。转移交互：聊天栏(ChatScreen)打开时右键灵动岛 ammo/fuel 图标 → 面板出现在鼠标位置（越界夹回）→ 选本队成员（离线置灰、显示每人 A/F 存量）→ 输入数量（上限 min(自己余额, 999-对方存量)）→ Confirm/Cancel，ESC 或点面板外关闭；面板打开期间鼠标/滚轮/按键/字符事件在面板区域内 setCanceled 拦截；过渡动画 150-160ms。
